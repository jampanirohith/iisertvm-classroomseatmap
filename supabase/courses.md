# IISER TVM course reference

Which course codes are the same course, for turning timetables into events. Built from the three course catalogues (dated 9 Aug 2024) and from the Varsha 2026 mid-sem and end-sem seating plans and class timetables.

## 1. Rules

1. **One line in part 2 or part 3 is ONE course, so it is ONE event**, however many codes it has. Codes of one course are the names it carries for different programmes, batches or levels (BS-MS, MSc, PhD, i2): one lecture, one hall, one time.
2. Codes joined by "/" (or listed together in one cell) in a seating plan row or a timetable cell are one course. Write them as one title with " / " between the codes, `DSC 323 / MAT 314 / MSM 405`.
3. **Codes on different lines are different courses.** Two different courses that share a hall at the same time are two events in that hall, never one event with a comma. Example: Jupiter, 23 Nov, 14:00-17:00 has `HUM 212` and `I2M 411 / MAT 4511`, which are two courses.
4. Never join courses because their titles look alike, they share a faculty, a hall or a time. Join only what the timetable itself joins, or what a line below joins.
5. A code seen alone in a timetable, whose line below has more codes, is still that line's course. If two codes of one line show up in the same hall at the same time, they are one event.
6. **Part 2 comes from the 2026 timetables and wins** over part 3 (the catalogues are older and some codes have changed or been reused). A code that is in neither is its own course; do not guess.
7. The same code can mean different courses in different batches (part 4). Never read a code as a title without checking its line. For a code listed in part 4, part 2 decides: join it with other codes only when part 2 does.

Code format (from the catalogue): `XYZ LSC` BS-MS core, `MSQ LSC` MSc core (`MS` + B, C, M or P), `XYZ LSCD` electives; `L` is the level (1 to 7); the digits after it are unique to the course; a trailing a, b, c, ab or bc marks a part-of-semester module. Subject codes: BIO biology, CHY chemistry, MAT mathematics, PHY physics, DSC data science, IDC interdisciplinary studies, HUM humanities, EES earth, environment and sustainability, I2B/I2C/I2M/I2P i2 sciences. The catalogue lists `EESS 201` and `EESS 202`; the 2026 timetables use `EES`, `EESA` and `AOE` codes that the catalogues do not list. In the timetables one lecture is often printed with a BS-MS code, an MSc code and a PhD code (6xx or 6xxx) together.

## 3. Catalogue courses, similar ones grouped (315 courses, 482 codes)

One row per course. **Cat. A** is the catalogue for batches 20-22 and MSc 23-24; **Cat. B/C** is the catalogue for batch 23 onwards (B) and its foundation courses (C). Several codes in a cell are cross-listed (one lecture). When both columns are filled, the two catalogues have the same course (same title and same syllabus) under different codes. "2026" gives the group number in part 2 when one of the codes is in the 2026 timetables, and the codes that group adds. "#n?" means only a reused code matches (see part 4), so that group may be another course.

How the rows were made: codes printed together on one line of a catalogue are cross-listed; the same course in the two catalogues is joined only when the title is the same and the syllabus text is largely the same, or when the code and the title are both the same. Nothing was joined on a similar title alone.
